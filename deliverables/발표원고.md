# 발표 원고 — X-ray Teeth Numbering / Reverse Registration / RF-DETR

## 1. 파노라마 X-ray 치아 번호화

핵심 메시지는 단순한 치아 존재 검출이 아니라, 각 치아를 box·class·mask로 구조화하고 최종 class를 FDI 번호로 바꾸는 것입니다. 데이터셋 코드는 32개 치아 class와 background 처리 차이를 흡수합니다. 따라서 모델 출력 index와 임상에서 사용하는 FDI 11~48 표기를 분리할 수 있습니다.

## 2. 치아용 RF-DETR 구현과 DINOv2 경량화

원본 RF-DETR 대비 `detr_teeth` 브랜치는 약 4,248줄을 추가했습니다. 핵심은 Kaggle/LabelMe/COCO 주석 통합, bbox와 mask를 함께 보존하는 증강, segmentation head, 원본 크기 복원 및 ONNX/CoreML 추론입니다. DINOv2 Tiny는 12개 layer를 유지하면서 hidden size를 384에서 192로, head를 6에서 3으로 줄였습니다. Transformer의 주요 연산과 파라미터가 폭의 제곱에 비례하므로 backbone 블록 규모는 구조적으로 Small의 약 1/4입니다. 이 수치는 실측 latency가 아니라 config 기반 규모 비교입니다.

## 3. Reverse-registration 원본 대비 변경

`origin/main`과 `nonrigid2d`를 비교하면 49개 파일, 약 17,062줄이 추가되고 471줄이 삭제됐습니다. 변경의 본질은 기존 기초 등록 코드 위에 파노라마 X-ray와 IOS를 잇는 2단 AI 정합을 추가한 것입니다. 먼저 `SimilarityReg2D`가 회전·이동·scale과 치열 곡선 계수를 추정하고, `NonRigidReg2D`가 dense 또는 anchor deformation field로 잔차 변형을 보정합니다. 마지막에는 2D 파노라마 좌표의 대응점을 3D world similarity로 올려 상악과 하악의 관계를 합성합니다.

## 4. Reverse-registration 안정화 기술

치열 곡선을 바꿀 때 x를 단순 scale하지 않고 arc-length를 보존해 인접 치아 사이의 물리적 길이를 유지했습니다. 치아 중심점은 raw 좌표 MLP 또는 feature-map sampling으로 모델에 주입하고, 순서가 있는 치열이라는 점을 attention pooling에 반영했습니다. ARAP loss와 robust rigid postprocess는 치아 하나가 비현실적으로 휘는 것을 막습니다. 반복 추론에서는 non-rigid deformation을 과도하게 반복하지 않고 pose residual 위주로 refine해 발산을 줄였습니다.

주의: DINOv2 Tiny 경량화는 `rf-detr_main`의 변경이며 `reverse-registration`의 변경은 아닙니다.

## 5. RF-DETR 핵심 기술

RF-DETR은 DINOv2가 이미지 표현을 만들고, ViTDet 방식 projector가 이를 multi-scale feature로 바꾼 다음, MS Deformable Attention decoder가 소수의 query로 box와 class를 직접 예측합니다. 별도 NMS 중심의 전통 detector와 달리 Hungarian matching으로 정답과 query를 1:1 배정하는 set prediction 구조입니다. two-stage proposal과 iterative box refinement가 query 품질을 높이고, Group-DETR은 학습 시 matching 기회를 늘리면서 추론 비용은 한 group으로 유지합니다. segmentation이 켜지면 query와 pixel feature의 내적으로 instance mask를 만듭니다.

## 발표 시 수치 사용 주의

- 저장소에는 최종 임상 성능(AP, Dice, latency)의 확정 비교표가 없으므로 PPT에 임의 성능 수치를 넣지 않았습니다.
- DINOv2 “약 1/4”은 hidden dimension 기준의 Transformer 지배 블록 규모 추정이며, 전체 모델 실측 결과가 아닙니다.
- reverse-registration의 변경량은 현재 로컬 `origin/main...nonrigid2d` Git 비교 결과입니다.
